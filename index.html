Hardware topology · Strix Halo PCIe fan-out

One 16-lane SoC, fanned out to ten drives + dual 10GbE

16 Zen 5 cores, 128 GB unified LPDDR5X, 16 general-purpose PCIe Gen4 lanes plus a dedicated USB4 rail. A Gen4 lane carries 1.97 GB/s — allocated as read from the live links:

Function Controller Link Throughput
4× NVMe (array under test) Lexar NM790 4TB Gen4 ×1 ea 1.97 GB/s ea
1× NVMe (OS) Intel 760p Gen3 ×4 3.94 GB/s
5× SATA bays JMicron JMB58x Gen3 ×2 shared 1.97 GB/s
2× Ethernet Realtek RTL8127 Gen4 ×1 ea 10 GbE ea
2× USB4 / TB5 Intel JHL9580 Gen4 ×4 ea 7.88 GB/s ea
Each array NVMe negotiates one Gen4 lane — the drives are ×4-capable, the slots present ×1 — so every array figure here is bounded to 1.97 GB/s per drive, 7.88 GB/s across four. The lane, not the SSD, is the bottleneck.

RAID10 writes both mirror copies (~2×). RAIDZ1 writes data + parity (~1.375×) — why it keeps up on write throughput despite parity compute. Read amplification ≈1.0 on both.

AI destination · not yet measured

Stream the models from the hot tier.

Tiered appliance thesis: keep weights + RAG indexes on hot NVMe, run inference in 128 GB unified memory (CPU+iGPU shared; GTT mappable toward ~100 GB+ when tuned — not discrete VRAM), park bulk corpora on cold SATA. Cold image load (Comfy / Qwen-Image) and MoE with --moe-stream-direct (llama.cpp) hit the hot pool — but unified memory hides the disk unless you force cold. Drop caches, cap ARC, verify with zpool iostat. mmap can lie; O_DIRECT + zfs set direct=always is the honest path. RAID10 vs RAIDZ1 above is how you choose that hot-tier layout under the ×1 tax. No inference numbers invented here.

Dual 10GbE multi-client saturation

Gated: both RTL8127 currently negotiate ~1 GbE — needs a 2.5/10G switch first. Then drive both ports with concurrent clients; compare pool layout vs NIC ceiling.

Why: proves whether the array or the network is the NAS bottleneck.

Storage

Why: 128 GB changes the “cold pool” story for both storage and AI.

Why: recordsize couples tightly to later MoE expert-slab reads.

Storage

Why: amplification should show up as watts and heat, not just GB/s.
